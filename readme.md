# Steps to work with Jupyter Notebook

1. Create a new folder to start working with
2. Open a terminal at that folder and create a virtual environment  
    - Both OS: python -m venv venv  
3. Activate the virtual environment
    - Mac: source venv/bin/activate
    - Windows: .\venv\Scripts\activate  
4. Install **jupyter** and **ipykernel** dependencies
    - Both OS: pip install jupyter
    - Both OS: pip install ipykernel
5. Create a .gitignore file and add the venv

## Jupyter Notebook in the browser
If you want to work in the browser instead of VS Code IDE you can run this command int he terminal and open the link:
    - Both Os: jupyter notebook

## Jupyter Notebook in VS Code
Tos start working with jupyter we need to make sure that Jupyter Extension is installed and then we can proceed creating files with the extension **.ipynb**
